# CIVIA

CIVIA es una plataforma móvil orientada a la gestión y seguimiento de reportes entre usuarios y organizaciones.

El proyecto se desarrolla como parte de la materia Diseño y Programación de Software Multiplataforma.

## Arquitectura prevista

- Mobile: React Native con Expo y TypeScript
- Backend: FastAPI
- Base de datos: PostgreSQL
- Contenedores: Docker
- Orquestación prevista: Kubernetes
- Integración: API REST

## Estructura del proyecto

La solución se organizará progresivamente en los siguientes módulos:

- `mobile/` — Aplicación móvil React Native
- `backend/` — API y lógica de negocio
- `database/` — Recursos y documentación de base de datos
- `infra/` — Docker y configuración de infraestructura
- `docs/` — Documentación técnica complementaria
